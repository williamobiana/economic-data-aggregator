## Second-brain integration (PATH = '/home/user/workspace/lab/second-brain')
- Vault project note: `Projects/<Your Project>.md`.
- Before starting work on a new topic or feature, run /obsidian-find on
  the topic to surface prior decisions from the vault.
- When a notable decision is made during work, run /obsidian-decide to
  record it against the <Your Project> project.
- After finishing a chunk of work or a session, run /obsidian-log to
  summarize it to the vault, then /obsidian-architect to refresh the
  codebase notes.
